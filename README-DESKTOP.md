# 桌面版专属工作流

此文件夹是完全隔离的桌面版发布环境。所有的开发、打包和 UI 自适应调试都在此处进行。

### 常用操作
1. **本地调试桌面版**：
   - 激活环境：`venv\Scripts\activate`
   - 运行：`python main_desktop.py`
2. **一键打包**：
   - 双击运行 `build_exe.bat`
3. **自适应调整**：
   - 修改 `ui_web/frontend/src` 中的代码。
   - 重新打包或使用 Vite 预览。

### 隔离原则
不要修改此文件夹外的源码，除非需要同步核心功能。
此文件夹内的修改不会自动反馈到主仓库，旨在为分发提供稳定的快照。
